scripts; the current versions of the same results live in `Output/`, `Output/analysis/` and
`Output/robustness/`.

|---|---|
| `stage_results_2026-09-27.pdf` | PDF snapshot of the nine main regressions (three tables per stage), as in the Progress Memo |
| `screenshots_2026-09-27/` | Four result screenshots used in the Progress Memo |
| `meeting_2026-09-30/` | Quick computations for the 30 September group meeting (descriptives, decomposition, cell sizes, equal weight per economy, economy-level rates); the one-off scripts were not kept |
| `midterm_2026-10-09/` | Outputs prepared for the 9 October midterm meeting: descriptives, Figures 1 and 2, and the decomposition that averaged Q over the contacted subsample. `joint_decomposition_contacted_sample.py` is that version of the script, kept for reference; it no longer runs from this location |

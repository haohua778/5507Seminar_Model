Notes. Specification (2): linear probability model weighted by `wgt`, with one dummy per economy and the demographic controls; reference group: pays less than monthly. Each row tests H0: b = 0. Events is the number of respondents with outcome 1. Estimate, cluster SE and t equal the main results; p, cluster t(74) uses CRV1 standard errors clustered by economy and the t distribution with G - 1 = 74 degrees of freedom. p, wild bootstrap is from the restricted wild cluster bootstrap (WCR; Cameron, Gelbach and Miller 2008). (i) The model is re-estimated without the tested regressor, keeping all other regressors, the country dummies and the weights, so the bootstrap data satisfy H0. (ii) In each of B = 9,999 draws every economy receives one Rademacher weight (+1 or -1, each with probability 1/2), and all restricted residuals of that economy are multiplied by it. (iii) The bootstrap outcome is the restricted fitted value plus the weighted residual; the full model is re-estimated on it. (iv) The CRV1 t statistic of the tested coefficient is computed as for the original estimate, measured from the null value 0. The p-value is the share of draws with |t*| >= |t|, and it does not use the t(74) distribution; a bootstrap p-value shown as < 0.0001 means that none of the 9,999 draws had |t*| >= |t|. The economy is both the cluster and the unit that receives a bootstrap weight (75 economies in every stage). The weights `wgt` enter by multiplying the outcome and every column of the design matrix, including the constant and the country dummies, by sqrt(wgt), which turns weighted least squares into ordinary least squares. The CRV1 variance includes the factor G/(G - 1) x (N - 1)/(N - K), with K = 88 parameters including the country dummies; the factor scales the original and every bootstrap t statistic by the same constant, so it does not change the bootstrap p-value. Random seed 20261026, set before each test, so all six tests use the same matrix of Rademacher weights. The simulation standard error of a bootstrap p-value is sqrt(p(1 - p)/B), at most 0.005 with B = 9,999.
